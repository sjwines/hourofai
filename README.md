# Drone Command: Operation Uplink

A free **Hour of AI** coding activity for grades 9-12, built as a Microsoft MakeCode Arcade skill map.
Students program an underwater Navy drone to collect data, dodge enemy sonar buoys, and upload their
findings to a ship. Then they build an **AI advisor** from if / else-if / else rules that recommends
**Collect**, **Upload**, or **Avoid**, and let it fly the drone on autopilot.

- **Play the activity:** https://arcade.makecode.com/--skillmap#github:sjwines/hourofai/forest.md
- **Teacher website** (lesson overview, standards, slides, worksheet, certificate): https://operationuplink.vercel.app

## What is in this repository

| Path | What it is |
| --- | --- |
| `forest.md` | The skill map: order of the levels, descriptions, tile pictures, and the certificate. |
| `forest/forest0.md` | The Finished Game (optional, always open). |
| `forest/forest1.md` to `forest5.md` | Levels 1 to 5: build the drone, ship, data, upload rule, AI advisor, and the win. A complete game, then the certificate. |
| `forest/forest6.md`, `forest7.md` | Optional Level 6 (autopilot) and Level 7 (Challenge Lab). |
| `assets/` | Pictures, animated clips, and the certificate used by the lessons and the skill map. |

The file names start with `forest` because the project began from a skill map template.

## A tip for students

Use the ocean maps that come with the game (the `choose ocean map` block). Please don't replace the ocean with your own tile map, because the data pods, buoys, and autopilot are built for these oceans.
